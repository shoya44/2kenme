# モック

`mock.html` を1枚開くと、4画面が端末フレーム付きで並ぶ。設計書（REQ-001 / FE-001）に対応した版2.0のモック。

| 画像 | 画面 | 対応 |
|---|---|---|
| `01_トップ画面.png` | トップ | FE-001 §4 |
| `02_結果画面.png` | 結果 | FE-001 §11 |
| `03_候補なし.png` | 候補なし | FE-001 §14 |
| `04_履歴シート.png` | 履歴シート | FE-001 §24 |

## 再生成

```bash
npx playwright@1.56 install chromium   # 初回のみ
node shot.mjs "$(pwd)"
```

`mock.html` はNoto Sans JPをGoogle Fontsから読み込む。オフラインで生成する場合はローカルの `@font-face` へ差し替える。

## 旧モック

版1.0（「運命の1軒」）のモックは `old/` に残してある。現行仕様ではない。差分は `old/README.md` を参照。

## 素材

- `shop.jpg` — 結果画面のプレースホルダー写真。版1.0のモックから流用したもので、実在店舗の写真ではない
- 端末フレーム・ステータスバー・アイコンはすべてCSS / インラインSVGで描画している。外部の画像素材は使っていない

## 注意

モックは寸法・余白の目安であり、確定値ではない。デザイントークンと数値の正はFE-001 §25。
