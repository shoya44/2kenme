# 運命の1軒 — 要件定義書

- 文書ID: REQ-001
- 版: 1.0
- 更新日: 2026-09-19
- 対象: MVP

## 1. 目的

飲み会の2軒目を決める際の「候補が多くて決められない」という迷いを減らす。

ユーザーは必要最小限の条件を設定して抽選し、**候補を1店舗だけ**受け取る。候補が合わなければNGで次の1店舗へ進み、合えばOKで決定する。

```text
条件を設定
  ↓
抽選する
  ↓
1店舗だけ表示
  ↓
NG → 次の1店舗
OK → 決定
```

一覧・ランキング・比較を行わないことをプロダクトの特徴とする。

## 2. 対象ユーザー

- 飲み会後に近場の2軒目を探したい人
- 店舗一覧を比較するより短時間で決めたい人
- スマートフォンで片手操作したい人

## 3. 提供形態

- スマートフォン優先のPWA
- ホーム画面へ追加可能
- アプリ本体はオフライン起動可能
- 店舗検索にはネットワーク接続が必要
- 店舗情報はHotPepperグルメサーチAPIを利用

## 4. 機能要件

| ID | 機能 | 要件 |
|---|---|---|
| F-01 | 現在地取得 | Geolocation APIで自動取得する。トップ画面には表示しない |
| F-02 | 条件設定 | 予算・ジャンル・人数・こだわり・距離を設定できる |
| F-03 | 抽選 | 条件に合う近隣店舗群からランダムに1店舗だけ表示する |
| F-04 | NG | 同一セッションで未表示の次候補を表示する |
| F-05 | OK | 店舗を履歴へ保存し、HotPepper店舗詳細へ遷移する |
| F-06 | 重複排除 | 同一セッションで同じ店舗を再表示しない |
| F-07 | 追加取得 | 候補が少なくなったら次の検索結果を先読みする |
| F-08 | 条件復元 | 前回使用した検索条件を次回起動時に復元する |
| F-09 | 履歴 | OKした店舗を最大20件保存する |
| F-10 | 店舗詳細 | HotPepper店舗URLを開ける |
| F-11 | 連絡先導線 | 電話番号を直接保持せず、HotPepper店舗詳細から確認する |
| F-12 | 候補0件 | 条件を1段階ずつ緩和して再検索できる |
| F-13 | PWA | インストール、アプリシェルのオフライン起動に対応する |

## 5. 検索条件

### 5.1 予算

- UI: スライダー
- HotPepperの検索用ディナー予算コードに対応する離散値
- 「指定なし」を含む
- スライダーの各ステップは1つの予算帯を表す

### 5.2 ジャンル

- UI: チップ
- 単一選択
- 「おまかせ」を選択可能

### 5.3 人数

- UI: `- / +`
- 1〜20人

### 5.4 こだわり

初期状態は折りたたむ。

- 個室
- 飲み放題
- 23時以降営業

### 5.5 距離

- UI: スライダー
- 300m / 500m / 1km / 2km

## 6. 画面要件

### 6.1 トップ画面

- 共通ヘッダー
- 予算スライダー
- ジャンルチップ
- 人数ステッパー
- こだわり条件（折りたたみ）
- 距離スライダー
- 「抽選する」ボタン

現在地は自動取得し、画面には表示しない。

### 6.2 結果画面

表示を以下に限定する。

- 店舗写真
- 店名
- HotPepper URL
- 徒歩時間
- 予算感
- 連絡先導線
- NGボタン
- OKボタン
- 条件変更

評価・レビュー・ランキング・大量のタグは表示しない。

### 6.3 補助UI

- メニュー
- 履歴
- エラー / 候補0件メッセージ

## 7. 抽選要件

1. 現在地・条件で最大20件を取得
2. クライアント側でFisher-Yatesシャッフル
3. 先頭1件のみ表示
4. NG時は現在店舗を表示済みにする
5. 次候補を即表示
6. 残候補が5件以下なら次ページ20件を先読み
7. 表示済みID・既存候補と重複する店舗を除外

同一セッションでは一度表示した店舗を再表示しない。

## 8. 候補0件時

以下の順で、ユーザー操作により1段階ずつ緩和する。

1. こだわり条件を解除
2. ジャンルを「おまかせ」
3. 距離を1段階拡大
4. 予算を「指定なし」

## 9. 非機能要件

### UX / デザイン

- スマートフォン片手操作
- 1画面1目的
- Apple HIGの考え方を参考
- ダークモード固定
- モノクロベース + 差し色1色
- 十分な余白
- 主要タップ領域は原則48px以上
- UIアイコンはSVGを使用
- 装飾目的のGlass表現は抑える

### 性能

- 抽選APIは通常通信環境で数秒以内の結果表示を目標
- NG時、候補が手元にあれば通信なしで即切替

### プライバシー

- 現在地をサーバーDBへ保存しない
- 現在地をlocalStorageへ保存しない
- APIキーをブラウザへ公開しない
- サーバー側で検索履歴を保持しない

## 10. MVP対象外

- 店舗一覧
- 評価・レビュー
- ランキング
- 地図上での検索地点指定
- 駅名検索
- 空席確認
- 投票
- ルーレット
- 音声入力
- お気に入り
- クラウド同期
- 終電連動
- 電話番号の直接取得
- 高度なオフライン店舗検索

## 11. 受入条件

- PWAとして起動・インストールできる
- 現在地を取得できる
- 条件を指定して抽選できる
- 結果は1店舗だけ表示される
- NGで別店舗が表示される
- 同一セッションで店舗が重複しない
- OKで履歴へ保存される
- HotPepper店舗ページを開ける
- 前回条件を復元できる
- 履歴を最大20件保持できる
- 候補0件時に条件緩和ができる
- APIキーがブラウザへ露出しない
- 現在地が永続保存されない
