# 運命の1軒 — データ設計書

- 文書ID: DATA-001
- 版: 1.0
- 更新日: 2026-09-19
- 対象: MVP

## 1. 方針

サーバーDBは使用しない。

```text
localStorage
sessionStorage
```

だけを使用する。

IndexedDB・永続検索キャッシュはMVPでは使用しない。

## 2. 保存データ一覧

| Key | 保存先 | 用途 | 保持 |
|---|---|---|---|
| `unmei:defaults` | localStorage | 前回検索条件 | 明示削除まで |
| `unmei:history` | localStorage | OKした店舗 | 最大20件 |
| `unmei:session` | sessionStorage | 現在の抽選状態 | タブ終了まで |

現在地は`unmei:session`内だけに保持する。

## 3. SearchCondition

```typescript
interface SearchCondition {
  budgetCode: string | null;
  genreCode: string | null;
  partySize: number;
  preferences: {
    privateRoom: boolean;
    freeDrink: boolean;
    midnight: boolean;
  };
  range: 1 | 2 | 3 | 4;
}
```

## 4. defaults

```text
unmei:defaults
```

```typescript
type SearchDefaults = SearchCondition;
```

例:

```json
{
  "budgetCode": "B001",
  "genreCode": "G001",
  "partySize": 4,
  "preferences": {
    "privateRoom": false,
    "freeDrink": true,
    "midnight": true
  },
  "range": 3
}
```

保存: 「抽選する」押下時。  
読込: App起動時。

## 5. Shop

```typescript
interface Shop {

  lat: number;
  lng: number;

```

## 6. session

```text
unmei:session
```

```typescript
interface SearchSession {
  location: {
    lat: number;
    lng: number;
  };
  condition: SearchCondition;
  currentShop: Shop | null;
  queue: Shop[];
  shownIds: string[];
  nextStart: number;
  hasMore: boolean;
  startedAt: number;
}
```

## 7. session更新

- 初回検索成功: 新規作成
- NG: `currentShop / queue / shownIds`更新
- 追加取得: `queue / nextStart / hasMore`更新
- 再抽選: 既存session破棄後に新規作成

## 8. 重複ルール

追加候補の店舗IDが以下のいずれかに存在する場合は除外する。

```text
shownIds
currentShop.id
queue[].id
```

実装時は`Set<string>`を利用してよい。

## 9. HistoryEntry

```text
unmei:history
```

```typescript
interface HistoryEntry {
  shopId: string;
  name: string;
  hotpepperUrl: string;
  budgetText: string | null;
  walkMinutes: number;
  decidedAt: number;
}
```

店舗写真・緯度経度は履歴へ保存しない。

## 10. 履歴ルール

- 最大20件
- 新しい順
- 同一`shopId`は1件のみ
- 再度OKした場合は古い同一店舗を削除して先頭へ
- 21件目追加時は最古を削除

## 11. Storage操作

`services/storage.ts`だけがWeb Storage APIへアクセスする。

```typescript
loadDefaults()
saveDefaults()
clearDefaults()

loadHistory()
addHistory()
clearHistory()

loadSession()
saveSession()
clearSession()
```

UIから直接`localStorage` / `sessionStorage`を触らない。

## 12. JSON破損

parse失敗時:

```text
該当Key削除
↓
初期値で継続
```

アプリ全体を停止しない。

## 13. プライバシー

### localStorageへ保存しない

- 緯度
- 経度
- 候補queue
- 表示済みID

### サーバーへ保存しない

- 現在地
- OK / NG履歴
- ユーザー設定
- 店舗履歴

B/Eはステートレス。

## 14. PWAとの関係

```text
Service Worker
  └─ アプリシェル

localStorage
  ├─ unmei:defaults
  └─ unmei:history

sessionStorage
  └─ unmei:session
```

API店舗情報の永続オフラインキャッシュはMVP対象外。

## 15. 型共有

API I/F型:

```text
shared/api-types.ts
```

Storage内部型はF/E側だけで管理し、B/Eへ共有しない。

## 16. 整合性ルール

| データ | ルール |
|---|---|
| partySize | 1〜20 |
| range | 1〜4 |
| budgetCode | nullまたは定義済みコード |
| genreCode | nullまたは定義済みコード |
| shownIds | 重複なし |
| queue | shownIds / currentShopと重複なし |
| history | 最大20件 / shopId重複なし |

## 17. 将来の移行条件

以下が必要になった場合のみIndexedDB等を検討する。

- 大量のお気に入り
- 大量の履歴
- 店舗情報の長期オフライン保持
- 複雑な検索キャッシュ
- クラウド同期
