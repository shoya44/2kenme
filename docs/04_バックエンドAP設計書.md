# 運命の1軒 — バックエンドAP設計書

- 文書ID: BE-001
- 版: 1.0
- 更新日: 2026-09-19
- 技術: Cloudflare Worker + TypeScript

## 1. 責務

B/EはHotPepper APIとの境界に限定する。

```text
受け取る
↓
検証する
↓
HotPepperへ問い合わせる
↓
アプリ用に整形する
↓
返す
```

B/Eでは抽選・履歴・session・DB・cacheを持たない。

## 2. API一覧

| Method | Path | 用途 |
|---|---|---|
| POST | `/api/search` | 現在地・条件から店舗候補を取得 |

## 3. Request

```typescript
interface SearchRequest {
  lat: number;
  lng: number;
  range: 1 | 2 | 3 | 4;
  budgetCode: string | null;
  genreCode: string | null;
  partySize: number;
  preferences: {
    privateRoom: boolean;
    freeDrink: boolean;
    midnight: boolean;
  };
  start: number;
}
```

## 4. 入力検証

| 項目 | 条件 |
|---|---|
| lat | -90〜90 |
| lng | -180〜180 |
| range | 1〜4 |
| budgetCode | null または許可済み予算コード |
| genreCode | null または許可済み形式 |
| partySize | 1〜20 |
| preferences | boolean |
| start | 1以上の整数 |

不正時は`400`。

## 5. HotPepperパラメータ

固定:

```text
format=json
datum=world
count=20
```

動的:

```text
key
lat
lng
range
budget
genre
party_capacity
private_room
free_drink
midnight
start
```

boolean条件がfalseの場合はパラメータを省略する。

位置検索では、HotPepper仕様上`order=4`を明示しない場合は距離順になるため、MVPでは`order`を指定しない。

## 6. 外部API

```text
https://webservice.recruit.co.jp/hotpepper/gourmet/v1/
```

```text
env.HOTPEPPER_API_KEY
```

Cloudflare Secretで管理する。

## 7. 外部APIエラー

HotPepperはAPIエラー時もHTTP `200 OK`を返すため、必ず`results.error`を確認する。

| Code | 内容 | アプリHTTP |
|---|---|---|
| 1000 | HotPepperサーバー障害 | 502 |
| 2000 | APIキー/IP認証 | 502 |
| 3000 | パラメータ不正 | 502 |

## 8. タイムアウト

HotPepper通信は約5秒で打ち切る。

| 状況 | Status |
|---|---|
| 正常 | 200 |
| fetch失敗 | 502 |
| HotPepper error | 502 |
| timeout | 504 |

自動リトライしない。

## 9. Response

```typescript
interface SearchResponse {
  shops: Shop[];
  paging: {
    nextStart: number;
    hasMore: boolean;
  };
}

interface Shop {
  id: string;
  name: string;
  photoUrl: string | null;
  hotpepperUrl: string;
  budgetText: string | null;
  lat: number;
  lng: number;
  distanceMeters: number;
  walkMinutes: number;
}
```

結果画面で使用しない外部API項目は返さない。

## 10. 0件

```json
{
  "shops": [],
  "paging": {
    "nextStart": 1,
    "hasMore": false
  }
}
```

HTTP `200`。

## 11. ページング

```typescript
const nextStart = resultsStart + resultsReturned;
const hasMore = nextStart <= resultsAvailable;
```

## 12. 徒歩時間

Haversine式で直線距離を算出。

```text
歩行距離 = 直線距離 × 1.3
walkMinutes = ceil(歩行距離 / 80)
```

## 13. HTTPステータス

| Status | 用途 |
|---|---|
| 200 | 正常 / 0件 |
| 400 | リクエスト不正 |
| 404 | 未定義API |
| 405 | メソッド不正 |
| 500 | Worker内部エラー |
| 502 | HotPepper通信 / APIエラー |
| 504 | HotPepper timeout |

## 14. モジュール

```text
worker/
├── index.ts
├── search.ts
├── hotpepper.ts
├── mapper.ts
├── validation.ts
└── geo.ts
```

- `index.ts`: routing / 共通エラー
- `search.ts`: 検索ユースケース
- `hotpepper.ts`: 外部API通信
- `mapper.ts`: Shop変換
- `validation.ts`: 入力検証
- `geo.ts`: 距離計算
