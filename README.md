# つぎどこ

2軒目を、1軒だけ。

飲み会の2軒目を決めるためのPWA。条件を設定して「さがす」と、近くの評判の良い店を **1軒だけ** 提案する。合わなければNGで次の1軒、合えばOKで決定。一覧・ランキング・比較は持たない。

店舗情報は [ホットペッパーグルメ Webサービス](https://webservice.recruit.co.jp/) を利用する。
